# 福運討伐戰

請先閱讀 [DEPLOY.md](DEPLOY.md)。

六種固定傷害，動態抽中機率；BOSS 扣血；獎勵階段位於血條下方；6 秒輪盤；特殊事件獨立觸發。


## v6 開場鎖定
主持人進房後按「開始討伐」，鎖定登記人數、BOSS HP、抽獎機率與抽獎順序。開始後不接受新玩家登記，既有玩家可重連；踢人不重新計算門檻或機率。主持人可代替當前玩家開始抽獎、揭曉特殊事件、確認結算。


## v7 UI 調整
- 主輪盤使用與特殊輪盤相似的置中浮動視窗，僅輪到玩家時顯示；背景仍可見 BOSS 血條。
- 移除獎勵級距獨立方框；血條下方原有解鎖里程碑仍保留。
- 最近抽獎紀錄改為全寬區塊、多欄響應式排列，展示全部紀錄。
- 主輪盤及特殊輪盤統一 4 秒；扣血數字 32px。


## v8 UI 調整
主輪盤改為 BOSS 橫幅旁的常駐區域（遊戲開始後依回合顯示），不再以彈出視窗遮擋血條。手機窄螢幕時自動移至 BOSS 區塊下方。只有特殊事件輪盤使用浮動視窗。
