ㄅ# v11 追擊目標調整：紫色籤子至最終討伐獎勵

- 啟動條件維持不變：完成抽獎人數嚴格超過 50%，且距離 490 元門檻仍缺超過該門檻 50% 的傷害。
- 啟動後將追擊期望目標調整為「紫色籤子門檻」與「最高討伐門檻」的中點。80 人時目標為 125,000；85 人時依開場鎖定門檻計算。
- 僅提高剩餘玩家主輪盤高傷害獎項的抽中機率；六種固定傷害值不變。隱藏輪盤 15% 觸發率與獎項機率不變。
- 每次結算後重新估算剩餘回合需要的平均傷害，所有獎項仍保有非零機率。
- 這是提高落入區間的機率，不是保證；若剩餘玩家太少，即使全部抽到 6480 仍可能無法達標。
- BOSS 血量、門檻與開場人數固定；只有追擊狀態下的後續輪盤機率例外可變動。
- 達到最高分數門檻不代表最高獎勵一定可發放；仍受 NT$100,000 預算降級規則限制。
