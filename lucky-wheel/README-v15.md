# v15 星耀樂透高還原 UI

以設計參考圖重製網頁的色彩、裝飾、面板、主輪盤、獎勵節點及橫幅。原始「發瘋啦！！」角色圖保持動作不變，存於 public/original-character.png。

沿用 v14 後端與抽獎規則。僅視覺 UI 更新，輪盤仍由後端決定結果。

本機啟動 `npm install && npm start`。本機可用 `http://localhost:3000/?preview=1` 觀看測試資料，不會改動真實房間；正式網域無法使用此預覽模式。

注意：這是以 HTML/CSS/Canvas 重製的可操作高還原版，而非直接貼設計圖。字體、素材和細節無法做到每像素完全相同。
