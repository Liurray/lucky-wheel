# v9 後半場追擊與天賞石揭曉

- 主持人開始時鎖定房間人數、BOSS HP、門檻與基礎機率。
- 已完成抽獎人數嚴格超過一半，且距離 490 門檻仍差超過其 50% 時，啟動後半場追擊模式。
- 追擊模式是對開場機率鎖定的**唯一例外**：只調整剩餘回合的六格抽中機率，不改變任何傷害值、BOSS HP 或門檻。
- 追擊以剩餘人數及目前傷害推算期望值，目標落在 490 與紫色籤子門檻之間；抽獎具隨機性，不能保證。
- 特殊事件 15% 觸發，獎項 40% 天賞石、30% +1000、20% +2000、10% +3000。
- 天賞石解鎖成功時全房間展示圖片 3 秒，之後才進入「知道了」結算。上限 6 顆，超額轉 +1000。
- 部署：npm install && npm start。注意既有房間的開場鎖定資料仍會保留。
