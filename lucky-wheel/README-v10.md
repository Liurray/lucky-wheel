# v10 入房及天賞石動畫修正

- 同房間同 ID：原連線離線後允許重新加入（即使換瀏覽器或裝置），保留原登記順序與抽獎紀錄。
- 同 ID 在線時禁止第二條連線搶佔。
- 主持人踢人後同房間該 ID 永久封鎖，並額外封鎖原瀏覽器 token；伺服器重啟後仍由 data.json 保存。
- 成功解鎖天賞石才播放 `/stone-reveal.png` 原圖 3 秒；播放完後才進入「知道了」結果。已滿 6 顆轉為 +1000 傷害不播放。
- 注意：僅以玩家輸入的 ID 作身份驗證，無密碼的房間無法防止其他人在玩家離線時冒用該 ID。正式公開環境若需防冒用，應加入玩家專屬登入憑證。
- 部署平台若使用暫存磁碟，`data.json` 可能不持久；請配置持久磁碟以保留封鎖名單。
